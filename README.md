# Writing Organisation System 

## Features 
-Keeps track of clients
-Keeps track of work to be done
-Flexible input

## Installation 

```
git clone https://github.com/limxuankai/Writing-Organisation-System/
``` 

Set up a virtual environment on your desktop

``` 
pip install -r requirements.txt 
``` 

And you're set to go! 
Delete ```Clients.sqlite``` to remove dummy data.
